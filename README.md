One program, one line: the safety warning label that should come printed on every human being. The program writes it to `entry.txt` in the output directory — a deadpan regulatory notice, in the exact wording and rhythm of a real printed label, about the one hazard every unit ships with: it has already decided the wet paint is dry, the stove is not that hot, and the instructions are for other people.

## Run it

```sh
node main.ts
```
